# Raportul

| Fișier | Conținut |
| --- | --- |
| `raport.pdf` | PDF-ul exportat din Overleaf, actualizat la fiecare livrabil (T4, final); numele rămâne `raport.pdf` |
| `refs.bib` | bibliografia exportată din Zotero (BibTeX), cel puțin 4 intrări la T4 |
| `figures/` | PNG-urile generate de notebook, folosite în raport |
| `src/` | sursele Overleaf (arhiva zip descărcată din Overleaf și dezarhivată), la T4 și la final |

Link-ul de vizualizare al proiectului Overleaf (îl completează responsabilul raportului, la laboratorul 4):

- Vizualizare (toată echipa și titularul): `<link de vizualizare>`

Link-ul de editare nu se pune aici: depozitul este public, iar oricine are cont Overleaf și link-ul de editare ar putea modifica raportul. Perechea de raport lucrează din invitația primită pe e-mail.

Structura raportului (4-6 pagini): Introducere; Date și metodă; Rezultate (două figuri din notebook, un tabel); Concluzii; Bibliografie; Declarație privind utilizarea instrumentelor AI; Contribuția fiecărui membru.
